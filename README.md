# Gartner_Hype_Cycle_Matplotlib
A mathematical model of the Gartner Hype Cycle using Numpy and Matplotlib. This model is used in my GitHub profile picture.

### The Cycle's Equation
The curve is defined by the following function (LaTeX): $$y = \frac{10x^{2}}{e^{0.6x}} + \frac{5}{0.5 + e^{-(x-15)}} + 0.1x$$
